This folder makes TSF animated shorts (vertical TikTok videos, 61-75 s, English narration).
For anything about an episode (topic, script, voice timings, the film, rendering) follow the skill in
`.claude/skills/tsf-shorts/SKILL.md`; `API.md`, `STORY.md` and `TOPICS.md` are next to it.

- Reply in the language the user writes in. Narration, on-screen text and captions are in English.
- Run commands from this folder (on Windows: `node scripts\make.mjs <name>`).
- `episodes/emu_war` is the reference episode; `episodes/_template` is the starting point for a new one.
